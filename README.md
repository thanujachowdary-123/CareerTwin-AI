# 🧠 CareerTwin AI – Personalized Career Intelligence System

CareerTwin AI is an AI-powered career analysis project that helps students and job seekers understand how well their resume matches a target job description. It analyzes the resume, identifies technical skills, detects skill gaps, calculates a job match score, and provides a personalized learning roadmap.

---

## 🚀 Features

- 📄 Upload Resume in PDF format
- 🤖 AI-based Resume and Job Description Matching
- 🎯 Career Readiness / Job Match Score
- 🛠️ Automatic Technical Skill Extraction
- ⚠️ Skill Gap Identification
- 📚 Personalized Learning Roadmap
- 🎤 Interview Question Generation
- 🧠 Career Profile Analysis
- 🗃️ Store Analysis Data using SQLite
- 🌐 Interactive Web Interface using Streamlit
- 📱 Simple and User-Friendly UI
